## What can it do?
You can drag the controls, rename or resize them, change fonts, copy & paste...
You can even change the theme and the backdrop the window uses! (Like the picture above)
All the controls will be save to a `sdc` file, format likes this:
```
/**Dialog Designer**/
dialog,Form1,DEF,DEF,481,311
Static,Example,208,91,100,50,微软雅黑,-16,400,0,0,0
```
Whatever, it just took my breath away!

## How does it work?
With my another project: [DarkMode WinAPI](https://www.github.com/yeskunkun/DarkMode-WinAPI) , I just modified it to paint the handle.
Even the System Native Font-chooser dialog is dark or transparent! (That project also handles filedialog or properties window!)
Of course, it has more excellent touch-screen support.

## How to use it?
First of all, you can see an empty indirect window in the main window (basics), to fill it with something creative, just select the control list on the left (except the 光标), click anywhere, then a button or else comes out, with a big name--EXAMPLE!!!
Rename them with the 属性 window on the right! It immediately shows changes to the control.
What's more, The font dialog supports dark mode! Besides, it has more excellent touch-screen support.
Last but not least, under the dialog, there's an edit that shows the code generated, it will save all the information of the controls.
